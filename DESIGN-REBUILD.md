# Portfolio and UXCraft redesign
Replaces repeated italic display headlines, cream chrome, numbered decoration, status dots, overused button arrows and boxed narrative sections across nineteen HTML entry points. Uses Space Grotesk, white and graphite, open layouts, overlapping project imagery and crisp cast shadows. The existing liquid control docks and interactive hero instruments remain available with reduced-motion support.

Removed unsupported session/conversion/review/performance claims from legacy project descriptions. Project evidence is the working demo itself. Functional numbers, chart sample data, contrast readings, game scores and source reference entries remain because they communicate actual controls or explicitly illustrative examples.

The catalog retains educational examples of design styles and motion techniques. They are study content, not the page's visual identity. Dithered-image generation is removed from the Creative Studio menu. Native content sections no longer fade on scroll; manually controlled studies retain their demonstrations.

Validation: the existing browser suite covers the catalog, theme persistence, resources, prototype tools, twelve motion exports, six scroll studies, PNG export, basket and fourteen games. The additional portfolio suite checks nineteen source entry points, four representative pages at four viewport widths, both portfolio modes, and uncaught browser errors. CI result must be checked before merging. No price, award or measured performance claim is made.

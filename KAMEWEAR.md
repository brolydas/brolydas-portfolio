# Kamewear storefront prototype
Original homepage and collection portfolio artwork are reused as CSS image crops rather than replaced with generated imagery. Archivo is an approximation of the unidentified mockup UI font; the original brush lettering and wordmark are preserved as artwork. Native scroll and requestAnimationFrame provide reversible zoom and depth, pointer parallax and sparse particles. MengTo Skills guidance consulted: cinematic-scroll-storytelling, scroll-scrubbed-object-handoff, animation-on-scroll, pointer-trail-emitter. Kage code and imagery are not copied. The product bag, size selection and filters are local demonstrations, not a commercial store. Prices are illustrative. Product art is sourced from existing mockups rather than separate production assets. No checkout, login backend, video or payment integration. Visual QA pending.

## Sakuga VFX
Integrated the MIT-licensed upstream core and actual button/input/toast custom elements from Justin Finkelman's sakuga-vfx, pinned at c3dabb173928a3ad2372183103caf2e6f50953d0. The shared core is included once. Kamewear palette and typography are retained; native link and filter behavior preserved. Native filter and primary CTA reactions use the core drawing functions. Modal sizes use local CSS feedback so the top layer does not hide the effect, and successful bag additions show the upstream toast. No unrelated controls added. Reduced motion falls back to the existing static confirmation. Browser regression checks added; not yet run.
